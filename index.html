🔧 Installatie Instructies

📋 STAP 1: Google Cloud Console Setup

  1. Ga naar console.cloud.google.com
  2. Maak een nieuw project: "BC Development Dashboard"
  3. Activeer de Google Drive API
  4. Ga naar "Credentials" → "Create Credentials" → "OAuth Client ID"
  5. Application type: Web application
  6. Authorized JavaScript origins: https://sites.google.com
  7. Kopieer je Client ID

🔑 STAP 2: Client ID invoeren

Open dit HTML bestand en vervang op regel ~170:

const CLIENT_ID = 'JOUW_CLIENT_ID_HIER.apps.googleusercontent.com';

📁 STAP 3: Folder IDs ophalen

  1. Open je projectmap in Google Drive
  2. Kijk naar de URL: drive.google.com/drive/folders/ABC123XYZ
  3. Het gedeelte ABC123XYZ is je Folder ID
  4. Vervang in de CONFIG hieronder de voorbeeldlinks met echte Folder IDs

⚠️ Belangrijk voor Google Sites:

  • Voeg in OAuth consent screen je domein toe als authorized domain
  • Publish status moet "In production" zijn (of voeg testgebruikers toe)
  • Herlaad de pagina na het invoeren van Client ID
